# ELMC image-layout-first segmentation

The ELMC canonical rebuild now creates question image crops from page layout
anchors before applying OCR quality checks. OCR is retained as a transcription
candidate and does not gate crop creation. Crops preserve the complete content
width so diagrams, tables, options, and mathematical notation remain attached.

The pipeline is fail-closed for missing page images, unreliable anchors,
multi-column layouts, and boundary overflow. Visual-backed questions are valid
canonical records when the source page contains the required visual information;
they are not rejected merely because OCR cannot describe the figure.

The v2 local artifacts and contact sheet are generated by
`scripts/stage7_elmc_canonical_segmentation_v2.py`. Source PDFs, page images,
crops, OCR text, and question records remain local-only under `.local/`.
